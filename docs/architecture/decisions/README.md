# Architecture decision records

Use one short record for a decision that materially changes data ownership,
security boundaries, infrastructure, or a shared product architecture.

## Naming

`ADR-NNN-short-decision-name.md`

## Template

```md
# ADR-NNN: Decision title

- Status: Proposed | Accepted | Superseded
- Date: YYYY-MM-DD
- Pull request: #NNN

## Context

What constraint or problem forced a choice?

## Decision

What are we choosing?

## Alternatives considered

What credible options were not chosen, and why?

## Consequences

What becomes easier, harder, or newly required?
```

ADRs explain decisions; they do not replace implementation documentation,
tests, safety runbooks, or current source code.
